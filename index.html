      Conjuntos de dados

      Como gerar os dados por bairro

      O script baixa do Portal de Dados Abertos do TSE a votação por seção, o cadastro de locais de votação (com bairro e coordenadas) e a lista de candidatos, e grava um arquivo por município e ano.

      npm install
node scripts/build-historico.mjs --uf RN --mun-nome "MOSSORO" --anos 2020,2022,2024
node scripts/build-historico.mjs --uf RN --todos --anos 2024
node scripts/build-historico.mjs --uf RN --mun-nome "MOSSORO" --anos 2026   # quando o TSE publicar

      O código do município é o do TSE (5 dígitos), diferente do código do IBGE. Com --mun-nome não é preciso saber o código.

      Fontes: TSE — arquivos oficiais de divulgação de resultados e Portal de Dados Abertos. Ferramenta independente, sem vínculo com a Justiça Eleitoral. Confira resultados oficiais em resultados.tse.jus.br.
